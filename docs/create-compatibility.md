# Create 6.0.10 / Minecraft 1.21.1 / NeoForge — v1.6.0

## Установка

Наш мод остаётся самостоятельным. Для расширенной механики положите рядом
`create-1.21.1-6.0.10.jar`. Create **не встроен** в наш JAR. Его наличие определяется
при запуске; конфигурация клиента и сервера должна совпадать.

Поддерживаемый диапазон намеренно ограничен `[6.0.10,6.0.11)`: другие версии Create,
Fabric/Forge-сборки и сторонние аддоны не объявляются совместимыми без проверки.

## Что меняется при установленном Create

| Функция | Без Create | С Create 6.0.10 |
| --- | --- | --- |
| Двигатель | Прямая линия, 40 об/мин | Настоящий `GeneratingKineticBlockEntity`, 40 об/мин, **2560 SU** |
| Вал | До 32 блоков, одна ось | Настоящий `KineticBlockEntity`, двусторонняя передача, нагрузка 0 SU |
| Сеть | Собственный ограниченный поиск | Расчёт Create: шестерни, редукторы, муфты, смена направления и скорости |
| Перегрузка | Не моделируется | Сеть останавливается; после снятия нагрузки запускается |
| Внешний источник | Только наш двигатель | Вал принимает вращение от источников Create |
| Редстоун | Пауза двигателя и топлива | Пауза **генерации** и топлива; внешний привод может продолжать вращать сеть |
| Ключ Create | Не требуется | Поворот и снятие блоков стандартным ключом |
| Очки инженера | Обычное сообщение ПКМ | Скорость, нагрузка/мощность источника и остаток топлива |
| Автозагрузка топлива | Воронки / ItemHandler | Также воронки, желоба и funnels Create через ItemHandler |
| Рецепты Create | Не загружаются | Дробление, прессование в блоки, нагреваемое смешивание, распиловка |

Топливо прежнее: уголь/древесный уголь, 1600 тиков на единицу, запас 64. Автоматика
видит только **запас**, но не горящую единицу. Извлечение и симуляция операций не
создают топливо. Ручные ПКМ и Shift-ПКМ сохранены.

Мощность двигателя — 64 SU на об/мин × 40 об/мин = 2560 SU. Несовместимые направления,
несколько источников, передаточные числа и ограничения сети обрабатываются **Create**.
Перегрузка не прекращает горение: для экономии угля остановите двигатель редстоуном.

## Пример

```text
уголь / funnel → наш двигатель → наш вал → вал Create → редуктор Create
                                                        ↓
                                                  наш вал → станок Create
```

Наш вал можно смешивать в одной линии с валами Create. Шестерни и редукторы подключайте
к торцам по их штатным правилам. Нет собственного ограничения «32 вала» в режиме Create.

**Конвейерный ремень прикрепляется к обычным валам Create.** В Create 6.0.10 проверка
точки крепления ремня жёстко привязана к его собственному блоку. Поэтому добавлен
обратимый крафт **наш вал ↔ вал Create, 1:1**. Используйте обычные валы Create в
местах крепления ремней, установки его кожухов и кронштейнов. Это не скрытый mixin,
изменяющий внутренние проверки Create.

## Обработка материалов

Все восемь рецептов имеют `neoforge:mod_loaded` и не требуют Create в обычном мире.

- Дробильные колёса: любая наша руда → **2 сырых кристалла**, ещё 1 с шансом 25%.
- Пресс над чашей: 9 сырых кристаллов → блок сырых кристаллов.
- Пресс над чашей: 9 слитков → блок стихийной стали.
- Нагреваемый миксер: 1 сырой кристалл → 1 слиток.
- Механическая пила: 1 железный слиток → 2 приводных вала.
- Два обычных shapeless-рецепта конвертации валов 1:1.

Обычные рецепты мода остаются доступными. Дополнительно исправлены старый рецепт
светильника (пробелы в шаблоне) и путь разблокировок рецептов для Minecraft 1.21.1.

## Сохранения и границы поддержки

- ID двигателя/вала и ключи `Fuel`, `Charcoal`, `BurnTicks` сохранены между бэкендами.
- Перед добавлением/удалением Create **сделайте резервную копию мира**. Удаление Create
  удаляет его собственные блоки; поведение сложной сети без него не сохраняется.
- Клиентский рендер использует фактическую скорость Create, включая остановку при
  перегрузке. Для наших моделей применяется обычный BER, а не отдельная Flywheel-визуализация.
- Не обещается работа двигателя как активного источника внутри движущихся contraptions,
  особые Ponder-сцены, прямое крепление ремня к нашему валу, кожухи/кронштейны на нём
  или совместимость со всеми сторонними аддонами. Для специальных деталей применяйте
  конвертацию в штатный вал Create.
- Клиентское изображение, интерфейс очков, ключ и сложные движущиеся конструкции
  требуют ручной проверки. Серверные GameTests не заменяют эту проверку.

## Воспроизводимые проверки

```bash
# JDK 21; сборка + JUnit + два отдельных сервера GameTest
./gradlew build
# только самостоятельный режим
./gradlew runVerifyStandalone
# только Create, точный официальный релиз включается автоматически
./gradlew runVerifyCreate
# клиент/сервер для ручной проверки с Create
./gradlew runClient -PwithCreate=true
./gradlew runServer -PwithCreate=true
```

`verifyStandalone` и `verifyCreate` имеют разные runtime classpath и каталоги мира
в `build/gametest/`. Тесты проверяют загрузку без отсутствующих Create-классов,
ожидаемое наличие Create, реальные RPM, источник → штатный вал → редуктор → наш вал,
перегрузку/восстановление, внешний мотор Create, редстоун, разрыв линии, NBT топлива,
симуляцию автоматической загрузки/выгрузки и условное наличие рецептов.

API сверялся с исходниками тега:
https://github.com/Creators-of-Create/Create/tree/mc1.21.1-6.0.10

Точная compile/runtime-зависимость: официальный релиз Modrinth `UjX6dr61`,
а не плавающая Maven-сборка ветки разработки. Create и его библиотеки не упаковываются
в наш JAR.
